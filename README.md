# 頭痛ログ

頭痛の度合い（0〜5）・服薬・現在地の気圧を記録し、気圧の変化と頭痛の関係を確認できる PWA です。
サーバーは使わず、データは端末（IndexedDB）と、ログインした Google アカウントの Google ドライブに保存します。

## 機能

- 頭痛の度合いをスライダーで記録（選択した日時も記録。あとから編集可能）
- 頭痛・服薬とも、「記録する」ボタンの上の日時欄で記録する日時を指定できる（既定は現在時刻。タップで過去の日時に変更。未来は不可）。さかのぼって記録する時は、その日時の気圧を Open-Meteo の過去データ（1時間ごと。前後を補間）から取って付ける。場所は現在地。取得できない時は気圧なしで保存する
- Google にログインしてオンラインの間は、Google ボタンの縁が緑に光る（動きを減らす設定の端末では、光らせず緑の縁だけ）
- 付箋風のメモ欄。メモのある記録はグラフに付箋マークが付く
- グラフの頭痛の丸・錠剤アイコン（錠数分を重ねて表示。0.5錠は半分）・付箋マークをタップすると、その記録の詳細（付箋メモ・写真）をポップアップで表示
- 服薬の記録（薬・錠数・メモ・写真）。薬は設定画面で追加・編集（名前・色・服薬間隔）・削除・並べ替え（▲▼。服薬を記録する時の選択肢の順になる）。名前を変えると過去の記録の薬名も更新。初期の薬（ロキソニン・カロナール・バファリン）は英語表示では Loxonin・Calonal・Bufferin
- 最後に薬を飲んでからの経過時間と、服薬間隔を決めている薬は次に飲めるまでの残り時間
- 現在地（都道府県・市区町村名つき）の気圧・天気・気温・湿度。直前6時間〜今後12時間の気圧の推移を15分刻みでグラフにし、2時間ごとに数値を表示。気圧が下がる見込みのときは警告
- アプリを開くたびに（画面に戻った時も）、その場所の気圧を自動で記録。頭痛・服薬の記録には、開いた時に取得した気圧を付ける
- 気圧・頭痛・服薬（錠剤アイコン）を時間軸で重ねたグラフ。横軸は記録の量に合わせて自動で伸縮（「全体」）し、6時間・1日・3日・7日・30日の切り替え、＋/－ボタン、2本指のピンチ、ドラッグでの移動ができる
- 気圧カードの「アドバイス」ボタンで、気圧の下降・上昇に応じたセルフケアのアドバイス（と共通の基本のセルフケア）を表示
- ヘルプ（使い方）ページ（`public/help.html`。日本語・英語）。設定画面の「ヘルプ・使い方」カードと、設定画面の右上の「?」ボタンから開く。アプリの言語（`?lang=ja` / `?lang=en`）に合わせて表示する。`help.html`・`privacy.html` は SPA ではない単独のページなので、Service Worker がアプリ本体に差し替えないよう `vite.config.ts` の `navigateFallbackDenylist` で除外している（照合は「パス＋クエリ」に対して行われるので、`?lang=` 付きも一致する形にしている）
- 日本語 / English の切り替え（設定画面。初回は端末の言語で自動判定）
- 画面の配色（自動＝端末のライト/ダーク設定に合わせる / ライト / ダーク）を設定画面で選べる
- 位置情報が許可されていない時は警告を出し、iPhone・Android・パソコン別の設定手順と「もう一度試す」を案内
- 設定画面の「データのエクスポート」で、記録を Excel（記録・気圧ログの2シート）・服薬の写真・データ（`headache-data.json`。ドライブの同期と同じ形式）にまとめて書き出す（LeadLog と同じ形）。Google ドライブの専用フォルダー（`Headache_Log`）の中に `Headache_YYYYMMDD-HHMM` フォルダーを作って保存するか、この端末に `Headache_YYYYMMDD-HHMM.zip` としてダウンロードする（ダウンロードはログインなしでも使える）。削除済みの記録は含めない
- 電波が届かない場所でも記録できる（オフライン対応）。記録は端末に保存され、ネットにつながると自動で Google ドライブへ同期し、その場所の気圧も記録する。気圧・場所が取れない時は、その情報なしで保存する。電波なしでアプリを開いてもログイン状態は保たれる（初回だけは、ネットにつないで開く必要がある）
- Google ログインと Google ドライブ同期（記録は月別の JSON、写真は画像ファイルとして専用フォルダー `Headache_Log` に保存。以前の「頭痛と気圧の記録」フォルダーは、初回の同期で名前を変えて引き継ぐ。
  端末間は更新時刻の新しい方を採用し、オフライン中の記録は復帰後に同期。薬の設定も `settings.json` として同期）

気圧・天気は [Open-Meteo](https://open-meteo.com/)、地名は [OpenStreetMap Nominatim](https://nominatim.org/)（どちらも API キー不要）から取得します。
地名は約1km単位で端末にキャッシュし、問い合わせを減らしています。

## 開発

```
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド (dist/)
npm run lint
npm test         # 同期・薬の設定・グラフ用データ・Excel 出力・地名整形などのテスト
```

`main` に push すると GitHub Actions が自動でビルドし、GitHub Pages に公開します
（https://headache.doitmyself.net/ 。独自ドメインは Value-Domain の CNAME と GitHub Pages の Custom domain で設定。旧 URL の https://fuuchan-lab.github.io/headache-app/ は転送される）。

Google ログインは既定で CapLog と同じ OAuth クライアントを使います。
別のクライアントを使う場合は `.env.example` を `.env.local` にコピーして `VITE_GOOGLE_CLIENT_ID` を設定してください。
Google Cloud Console の「承認済みの JavaScript 生成元」に、アプリを開く URL の origin
（例: `http://localhost:5173`、`https://headache.doitmyself.net`）を登録する必要があります。
